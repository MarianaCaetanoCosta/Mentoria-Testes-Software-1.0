## Organização

Cada projeto possui seu próprio README com:

- objetivo;
- stack utilizada;
- estrutura de diretórios;
- pré-requisitos;
- comandos de execução;
- comandos ou orientações para relatórios;
- documentação das principais tecnologias utilizadas.

Arquivos de IDE, diretórios de build e resultados gerados de execução foram mantidos fora da consolidação quando não são necessários para reproduzir os testes. O código e os arquivos de configuração essenciais dos projetos foram preservados.
