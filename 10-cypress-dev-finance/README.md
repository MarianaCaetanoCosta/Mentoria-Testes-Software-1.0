# Automação E2E com Cypress — Dev Finance

Projeto de automação de testes E2E desenvolvido durante o Aulão de Cypress da Mentoria em Teste de Software 1.0.

## Aplicação testada

[Dev Finance](https://devfinance-agilizei.netlify.app/)

## Tecnologias

- Cypress 13.7.3
- JavaScript
- Node.js

## Escopo

O projeto contempla a prática de automação E2E utilizando Cypress, incluindo identificação de elementos, comandos de interação e validações da aplicação.

## Origem

Projeto desenvolvido como atividade prática da Mentoria em Teste de Software 1.0, utilizando uma aplicação diferente da Lojinha principal do portfólio.

> O código de testes deste módulo será consolidado a partir do repositório original da atividade, preservando sua origem e histórico.
